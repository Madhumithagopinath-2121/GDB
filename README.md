# GLOBAL DIGITAL BANK

A Python-based digital banking system developed to demonstrate core
Object-Oriented Programming concepts through a series of progressive activities.

## Concepts Covered

- Classes & Objects
- Encapsulation
- Validation
- Exception Handling
- Custom Exceptions
- Inheritance
- Polymorphism
- Abstract Classes
- Template Methods
- Modular Programming

## Features

- Account creation and management
- Deposits and withdrawals
- PIN validation
- Account status management
- Multiple account types
- Interest calculation
- Error and exception handling

## Technologies

- Python
- Object-Oriented Programming

## Activities

The project is developed progressively across **Activities 1–12**, with each
activity introducing and implementing new banking features and OOP concepts.
